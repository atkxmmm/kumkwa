# คุ้มกว่า

แอปเทียบราคาต่อหน่วย ใส่ขนาดกับราคาแล้วรู้ทันทีว่าตัวไหนคุ้มกว่า รองรับโปรซื้อแถม ชิ้นที่ 2 ลด ราคาเหมา และลดเป็นบาท
ไม่มีโฆษณา ใช้ได้แม้ไม่มีเน็ต ข้อมูลเก็บในเครื่องเท่านั้น

## ติดตั้งบน iPhone
1. เปิดลิงก์แอปใน **Safari**
2. กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

## อัปเดตแอป
แก้ไฟล์แล้วเปลี่ยน `VERSION` ใน `sw.js` ทุกครั้ง โทรศัพท์จะได้โหลดของใหม่

## เกม: กิลด์ยามดึก (`/game`)
เกมผจญภัยแฟนตาซีแบบ idle กาชา ภาพพิกเซล เปิดที่ลิงก์แอปแล้วต่อท้ายด้วย `game/` ติดตั้งลงหน้าจอโฮมได้แบบเดียวกัน
- ทีม 3 คนเดินสำรวจแผนที่มุมบน สู้มอนเอง แตะมอนเพื่อสั่งรุม แตะพื้นเพื่อพาเดิน
- ล้มมอนครบจำนวนแล้วบอสโผล่ บอสชาร์จท่าเป็นวงแดง: หนีออกจากวงหรือแตะบอสให้มึน
- ฮีโร่มีสกิล 2 อัน + สกิลติดตัว คอมโบธาตุไฟ/น้ำแข็ง
- มอนดรอปอุปกรณ์สุ่มค่าพลังเสริม ตีบวก +1 ถึง +10
- ชงเรียกฮีโร่/อุปกรณ์ด้วยเมล็ดกาแฟ มีภารกิจรายวัน
- อยากใช้ภาพที่เจนเอง ดู `game/PROMPTS.md`
- แก้ไฟล์เกมแล้วเปลี่ยน `VERSION` ใน `game/sw.js`
